I’m Youngchae Son, a Ph.D. student at Dongguk University (Seoul), working with Prof. Soochul Lim in the Interactive Robotics Lab. I build intelligent robot control and learning systems using vision-language foundation models, with a focus on Vision-Language-Action (VLA) pipelines that connect perception and language to action. My current interests include robot learning, grasping and manipulation, and scalable approaches toward Physical AI.
